# Neptasy
# ⚽ Neptasy

Neptasy is a modern fantasy sports and social engagement platform where users can:

- 🏆 Play Fantasy Premier League & World Cup Leagues
- 📝 Create and share blog posts
- 📲 Share content across social media
- 🎉 Create or join virtual and in-person sports events
- 🍻 Watch live matches together in sports bars
- 👥 Build communities around football and sports culture

---

## 🌐 Live Applications

### Frontend
🔗 https://neptasy.vercel.app



# 🚀 Features

## ⚽ Fantasy League System
- Create private/public fantasy leagues
- Join Premier League fantasy competitions
- Upcoming FIFA World Cup fantasy tables
- Real-time points tracking
- Player selection and rankings
- Combined leaderboard scoring

---

## 📝 Blogging Platform
Users can:
- Write sports blogs
- Share match predictions
- Post transfer rumors and opinions
- Interact through comments and likes
- Share blogs on social media

---

## 🎉 Events & Match Meetups
Neptasy allows users to:
- Host virtual watch parties
- Create local sports meetup events
- Join live screenings at bars/restaurants
- Organize football tournaments
- RSVP and interact with attendees

---

## 📊 Admin Dashboard
Admin panel includes:
- Total users
- Total posts
- Total blogs
- Total selected players
- Combined fantasy points
- User and content management
